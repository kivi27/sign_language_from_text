Text to Sign Language (ASL fingerspelling)

1. pip install pillow
2. python text_to_sign.py            (opens the GUI)
   python text_to_sign.py "hello"    (saves sign_output.png)

Keep the "signs" folder next to text_to_sign.py.
J and Z are signed with motion; their images show the movement.

Sign images come from github.com/FaizD18/ASL-Translator (assets/letters),
which lists an MIT license in its README. Credit to that project.
